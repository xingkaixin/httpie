# HTTPie Go 迁移

以用户提供的 HTTPie 3.2.4 源码为行为基线，发布命令行程序。桌面客户端共用同一请求核心，不在基线差分范围内。先记录契约，再实现，再用同一输入验证 Python 和 Go 的外部行为。

- [项目目标](goals.md)：范围、基线、验收条件。
- [架构](architecture.md)：模块职责与数据流。
- [功能清单](features.md)：命令、参数、输入和输出契约。
- [迁移计划](migration.md)：按依赖关系拆分实现和提交。
- [验证记录](validation.md)：可复现的差分与集成检查。
- [兼容性复审](review.md)：按内置功能核对源码、修复遗漏和回归证据。
- [性能报告](performance.md)：进程耗时、峰值 RSS 和原始测量数据。

未通过验证的项目不能标为兼容。实施进展、已知差异及测量结果记录在各文档中。
