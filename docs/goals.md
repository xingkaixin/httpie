## 范围

提供 `http`、`https` 和 `httpie` CLI。保留全部内置 CLI 功能，包括配置、会话管理、认证、网络、输出和下载。用户已确认不兼容第三方 Python 插件，因此不提供插件安装、Python 插件执行或任何 SDK。Go 实现置于 `internal/`，不承诺 Go 库接口。

所有开发直接在 `main` 上进行，按可审阅的功能批次提交。Go 版本由项目 `mise.toml` 固定，构建、测试均通过 mise 执行。

## 验收条件

1. 内置 CLI 参数、别名、重置选项、组合规则和退出码保持一致。
2. 相同输入产生等价的请求，保留重定向、认证、会话和文件行为。
3. 重定向输出保持字节正确；终端输出保留格式化、颜色和流式行为。
4. CLI 运行不依赖 Python。Python 只用于基线验证和开发脚本。
5. 在同一机器、同一服务和同一输入下测量耗时及 RSS，不接受已证实的性能退化。启动、短请求、大文件必须分别测量。
6. 不把“选项可解析”当作“功能已兼容”，不把局部测试通过当作全量兼容证明。
