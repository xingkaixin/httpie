# 迁移记录

开发在 `main` 进行，先提交目标、架构、功能清单和验证方法，再分批实现。

## 实现批次

1. **文档与基线**：记录压缩包版本和校验值，提取 54 项参数契约，明确只提供 CLI、不兼容第三方 Python 插件。
2. **请求构建**：mise 工具链、参数及重置语义、URL、嵌套 JSON、查询、头部、stdin、原始文件、表单与 multipart。
3. **网络与认证**：HTTP/1.1、代理、空闲超时、压缩、重定向、认证及正文重放。TLS 改用 OpenSSL，覆盖标准 Go TLS 无法表达的密码套件配置。
4. **输出**：终端/管道分流、头部与 JSON 排序、XML、字符集、颜色、二进制抑制、流式输出、元数据。
5. **CLI 与持久化**：三个入口、配置、会话、Cookie、管理帮助、参数导出、会话升级、更新检查、下载和续传。
6. **兼容修正与验证**：原版差分、旧格式状态对比、本地 TLS/代理集成测试、竞态与静态检查、进程耗时及 RSS 测量。

## 已修正的兼容问题

- 请求参数的重置顺序、重复 JSON 键、浮点数表示、非有限 JSON 值和路径转义。
- multipart 字段 quoting、空 multipart、文件 MIME 类型和 Content-Length。
- `--path-as-is` 的原始 URL 路径，以及请求头、认证头和会话头的顺序。
- 原始 deflate、流式输出尾部、JSON/XSSI、XML 声明和命名空间。
- CA 文件延迟加载、加密客户端私钥、TLS cipher DSL、HTTPS 代理隧道。
- SOCKS4/4a/5/5h 的协议与 DNS 语义、代理握手超时。
- 只读响应头时及时关闭正文连接；续传时先验证 Content-Range。
- 保留旧会话的字段结构和头部顺序，清理过期 Cookie，保留只读会话语义。

具体检查和测量见 [验证记录](validation.md)、[性能报告](performance.md)。CI 配置已写入仓库；当前仓库没有 remote，尚未执行远程 CI。
