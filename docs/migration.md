# 迁移计划

按以下顺序开发，每批提交同时记录验证结果。

1. 文档及基线：版本、目标、选项清单、兼容边界。
2. 工具链和请求构建：mise、命令入口、参数、URL、请求项、离线输出。
3. 网络和状态：HTTP、代理、TLS、认证、重定向、超时、压缩。
4. 输出和文件：格式化、字符集、流式输出、下载、续传。
5. 配置和管理：会话读写与升级、默认参数、管理命令。
6. 验证和修正：差分测试、集成测试、性能测量、文档更新。

提交必须描述实际完成的行为。存在兼容缺口时继续修复；若外部条件阻止验证，记录具体阻塞和未验证范围。

## 已实施

- 请求构建：54 项参数清单校验、参数重置、URL、嵌套 JSON、重复查询、表单、multipart、原始文件与 stdin。正文来源支持重新打开，文件不整体读入内存。
- 首批行为测试：请求方法、URL、正文、类型、输入冲突及上游参数清单；`go test ./...` 通过。端到端兼容尚待差分验证。
