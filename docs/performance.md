# 性能报告

测量日期：2026-10-11。机器：Apple M1 Pro，macOS 27.0.1 arm64。

Go 1.27.2 / OpenSSL 4.0.3；Python 3.11.15 / OpenSSL 3.5.5；HTTPie 源码版本 3.2.4。Python 依赖见 `scripts/reference-requirements.txt`。

## 方法

执行 `mise run bench`。每个场景、每个实现先预热 3 次，再独立运行完整 CLI 进程 20 次。耗时包括进程启动和退出，不包括构建、环境安装与服务端启动。正文丢弃到空设备；上传文件预先创建。

HTTP 和 HTTPS 都使用本机 Python 服务。HTTPS 使用同一个临时 RSA 证书，两端均传入 `--verify=no`。关闭更新检查、清除代理环境变量。依次执行两种实现，不与其他测试并行。

中位数和 P95 来自 20 次进程耗时；峰值 RSS 通过额外一次 `/usr/bin/time -l` 运行读取，涵盖 Go 堆和 OpenSSL 原生内存。RSS 单位为 MiB。

## 结果

| 场景 | Python 中位数 ms | Go 中位数 ms | 加速倍数 | Python RSS MiB | Go RSS MiB |
| --- | ---: | ---: | ---: | ---: | ---: |
| 版本查询 | 121.503 | 13.732 | 8.85× | 41.797 | 19.156 |
| 离线 JSON | 128.580 | 21.546 | 5.97× | 42.297 | 23.750 |
| HTTP 小请求 | 134.423 | 23.220 | 5.79× | 43.938 | 23.859 |
| HTTP 下载 32 MiB | 163.483 | 29.061 | 5.63× | 47.812 | 24.078 |
| HTTP 上传 32 MiB | 154.375 | 59.089 | 2.61× | 44.125 | 24.188 |
| HTTPS 小请求 | 134.374 | 18.108 | 7.42× | 44.625 | 23.688 |
| HTTPS 下载 32 MiB | 174.946 | 44.655 | 3.92× | 48.109 | 27.172 |
| HTTPS 上传 32 MiB | 163.017 | 116.814 | 1.40× | 44.719 | 29.250 |

8 个场景的中位耗时、P95 和峰值 RSS 均低于 Python 基线。加速 1.40–8.85 倍，RSS 降低 34.6%–54.2%。

原始数据（含 P95、环境和样本数）见 [performance.json](performance.json)。

这些结果适用于本机及上述输入。网络延迟、证书验证、终端高亮、不同文件大小和不同平台可能改变比例。32 MiB 场景用于验证流式传输和内存，没有用启动基准推断大文件吞吐。
