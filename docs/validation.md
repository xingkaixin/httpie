# 验证与性能

## 必要验证

本次迁移的核心要求是外部行为保持一致，故需要行为级测试。避免为内部包装、简单转发和实现结构增加测试。

- 从压缩包提取原版，在隔离 Python 环境安装；生产二进制不调用该环境。
- 同一命令分别运行 Python 和 Go，比较退出码、请求方法、URL、请求头、正文和输出。
- HTTP 测试使用本地服务，覆盖响应状态、重定向、Cookie、认证、TLS、压缩、超时、流、下载和续传。
- 输出时间、随机 multipart 边界和服务端日期等非确定值单独归一化；不能归一化实际业务内容。
- 终端和管道模式分别验证。选项清单取自上游语法树，防止漏参数。
- 执行 Go 格式检查、`go vet`、行为测试和竞态检查。

## 性能

使用已构建的二进制与已安装的原版比较，排除编译和依赖安装时间。固定本地服务、请求体及运行次数。记录机器、系统、Go/Python 版本、样本数、中位数、分位数及峰值 RSS。

场景：`--version`、离线 JSON、小型本地请求、较大响应下载、较大文件上传。启动开销和大文件吞吐分开判断，不用单个微基准概括全部性能。
